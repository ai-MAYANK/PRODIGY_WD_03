# ❌⭕ Tic-Tac-Toe Game

A responsive and interactive **Tic-Tac-Toe (X & O)** game built using **HTML**, **CSS**, and **Vanilla JavaScript**. The game allows two players to compete on the same device with automatic winner detection, draw detection, and game reset functionality.



---

## 📌 Project Overview

Tic-Tac-Toe is a classic two-player strategy game where players take turns placing **X** and **O** on a **3×3 grid**. The first player to align three symbols horizontally, vertically, or diagonally wins the game. If all cells are filled without a winner, the game ends in a draw.

The application features a clean and responsive interface, making it playable across desktops, tablets, and mobile devices.

---

## ✨ Features

### 🎮 Gameplay
- Two-player mode (Player X vs Player O)
- Alternate turns automatically
- Prevents overwriting occupied cells
- Automatically detects the winner
- Detects draw (tie) condition
- Winning message display
- Disable board after game completion

### 🔄 Game Controls
- Reset Game button
- New Game button after a match ends
- Restart anytime without refreshing the page

### 🎨 User Interface
- Modern and minimal design
- Responsive 3×3 game board
- Smooth button interactions
- Clean typography
- Mobile-friendly layout

### 📱 Responsive Design
Optimized for:
- Desktop
- Tablet
- Mobile
